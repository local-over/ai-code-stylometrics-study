## 📌 Abstract

The integration of Large Language Models (LLMs) into the software engineering lifecycle has enabled automated code synthesis across diverse programming languages. However, code generated by synthetic models exhibits structural, stylometric, and architectural patterns that fundamentally diverge from production code authored by human engineers. 

This repository contains the dataset, scripts, and formal research paper for an empirical comparative study across **136 complete code implementations**. We contrast human-authored standard library routines written prior to the LLM era (2017–2018 reference code from React 16, Go 1.10, Redis 5.0, Linux Kernel 4.14, Rust stdlib, PyTorch 1.0, and FastHTTP) against contemporary frontier synthetic models (**Google Gemini 3.5 Flash**, **OpenAI GPT-5.6 Sol**, and **Anthropic Claude Sonnet 4.6**).

## 🔍 Key Research Findings & Cognitive Paradigms

### 1. Human Cognitive Paradigm (*Hardware-First & Memory-Aligned*)
- **Bitwise Register Efficiency**: Humans use direct bitwise arithmetic (`(index - 1) >>> 1`) for binary min-heap index calculation in JavaScript runtime engines.
- **Hidden Struct Safety**: Human engineers enforce unwritten memory safety invariants. In Go's `strings.Builder`, human code includes a self-pointer check (`b.addr != b`) to trigger a runtime panic if the struct is illegally copied by value.
- **Single-Pass Flat Execution**: Humans minimize stack allocations by flattening loop control flow with early guard clauses (`if (!obj) return false;`).

### 2. Synthetic Cognitive Paradigm (*Pedagogical Abstraction & Token Trajectories*)
- **Micro-Helper Over-Fragmentation**: LLMs decompose simple 15-line algorithms into 3 to 5 micro-helper functions (e.g., `_remove`, `_add_to_head`, `_pop_tail` in LRU caches), increasing stack frame creation overhead by **+306%**.
- **Math Abstraction Truncation**: LLMs substitute CPU bitwise operations with floating-point arithmetic abstractions (`Math.floor((i - 1) / 2)`).
- **Trivial Echo Comments**: Models frequently document syntax line-by-line (`# Increment counter`, `// Set key`), reflecting pre-training token patterns from online tutorial code.
